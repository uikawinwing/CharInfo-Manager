# 通用身份别名、匿名面板与世界书触发桥（设计与阶段性接口）

## 状态

此文档定义通用协议。已增加纯数据注册表和安全投影实现；**ST 生成前的世界书触发桥、Chat Variables 持久写入和全 UI 防剧透尚未接线与实测**。不要把示例解释为现成可运行的按钮或已完成的端到端能力。

## 实体与知识分离

- 每个实体一个不可由真名、职阶、种族推算的 `npc_...` ID。面具、化名、变身、Saber/Caster 等仅是公开称谓，不能当数据库主键。
- 一个人可同时有多个别名，同一职阶可属于多个人；若当前场景无法唯一定位，就不做自动真实身份绑定。
- 可信 `realName` 来自明确的世界书人物条目或用户确认，不以 LLM 的猜测、`<char_info>` 内的 `__identity_view` 充当授权。
- 玩家公开知识、旁人知识与人物真实资料分开；揭晓姓名不代表揭晓所有技能和背景。

## 数据结构（当前聊天变量）

```yaml
char_info:
  identityRegistry:
    version: 1
    byId:
      npc_e8f213a4:
        id: npc_e8f213a4
        realName: 阿尔托莉雅 # 管理层绑定，不进入玩家可见面板
        publicName: Saber
        aliases: [Saber, 剑士]
        visibility: masked
        knownFields: [在场]
        publicFacts:
          身份: 自称剑士
        worldbookTargets:
          - book: 英灵资料
            uid: 42
```

`realName` 和世界书的 `book/uid` 必须在聊天级管理变量中绑定；不得写进 `<char_info>`、HTML 注释或名字可见的状态栏。保存时只更新该聊天的数据，不能修改全局世界书。

## LLM 公开消息协议

```yaml
<char_info>
__entity_id: npc_e8f213a4  # 如果没有既有可信 ID，则输出 new
__identity_view: masked      # 请求值，不是可信授权
姓名: Saber
种族: 未知
身份: 自称剑士
</char_info>
```

`__entity_id` 是匿名引用，不是背后真名的编码。既有世界书确定的人物可在私有映射预绑定 ID。没有可信链接时，扩展产生新 ID，后续复用；仅凭“这个人自称 Saber”不能自动合并到现有 Saber。

## ChatInfo Manager 对外显示

1. 角色列表、卡片标题、头像、种族、身份、属性、技能、装备、法则与背景统一由 `projectKnownCharacterData` 获取玩家可见投影。
2. `masked/partial` 默认只返回明确列于 `knownFields` 或 `publicFacts` 的内容；未知不是空装备，也不是零属性。
3. 角色资料编辑器、世界书角色库、图片配置、诊断日志、复制/导出和原始消息回退必须复核：任何暴露真实姓名的入口都属于泄露。
4. 改名/揭晓改变显示投影，不更换 ID，不重置好感度、装备、战斗状态与历史；历史面板保留创建当时的知识快照。

## 真名世界书如何在代号聊天中触发

ST 原生 World Info 通过**聊天扫描的关键词**触发，并不会自动读取 CharInfo Manager 的 `realName` 映射。因此**仅保存映射，不会令原生世界书自动触发**。

所需的是**生成前**桥接器（不是回合后修改面板）：

1. 读取当前聊天唯一的实体绑定；从最近发言/场景角色 ID 判断哪些实体当前需要载入。
2. 每个实体通过 `resolveIdentityWorldbookTargets` 获取明确的 `book+uid`，而非把通用代号 Saber 全局注册到多人的角色关键词。
3. 生成前使用经验证的 ST/TavernHelper lorebook API 让**本聊天**需要的目标条目参与该次生成；若 API 只能写条目，应使用当前聊天的影子世界书，保持原公共世界书不变，并避免目标条目长期开启。
4. 如果尚不能可靠在 World Info 检索之前注入匹配信息，就不得声称桥接成功；不得往玩家聊天正文、公开日志或 `<char_info>` 添加真实姓名充当触发词。
5. 只有在匹配唯一、场景证据成立且通过章节／权限限制时才能加载；若两位 Saber 同场而无法区分，分别等待 ID 指向，不群发所有 Saber 真身设定。

注意：**模型获得真实人物的世界书正文不等于玩家获得它**；LLM 输出仍需要隐瞒未公开身份。单靠提示词不能强制确保不剧透，浏览原始世界书/变量的作者仍可查看全知数据。

## 关键回归案例

- 两位 Saber 不同实体 ID；代号相同但不能互触发世界书。
- 角色变装/换名后原本已知关系与属性状态保持在同一个 ID。
- 戴面具时姓名、种族、法则、宝具、头像和内部日志不泄露；揭面后只升级有剧情证据的字段。
- 世界书条目不会因单独出现 `Saber` 而注入另一角色的真名资料。
- 换聊天、回滚、swipe、编辑历史面板、导出/复制及插件未加载时不能意外揭露隐藏资料。
