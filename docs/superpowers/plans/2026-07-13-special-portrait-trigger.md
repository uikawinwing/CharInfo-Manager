# 特殊立绘触发与失败回退执行计划

## 目标

在不改变现有 Venus 专属占位符行为的前提下，为 `char_info` YAML 增加 `特殊立绘` 触发：

1. `__char_info_ref: special_npc_01_venus` 始终优先使用 Venus 专属资料、主题和立绘。
2. 无专属占位符时，`特殊立绘: <http(s) 图片地址>` 使用通用特殊 NPC 面板，并保留当前 YAML 的种族、稀有度和其他资料。
3. 无以上条件时，继续使用普通 `char_info_viewer`。
4. 特殊面板图片加载失败时提供“重试”和“使用普通版”；失败原因不做无法确认的归因。

## 实施步骤

1. 在 YAML 规范化和视图模型中识别 `特殊立绘`，仅接受 HTTP(S) 地址，并为其生成通用特殊 NPC profile。
2. 让显式 `特殊立绘` 覆盖姓名静态映射；专属占位符仍在更上层替换资料，保持最高优先级。
3. 在特殊 NPC 面板内管理图片加载失败、用户触发的缓存刷新重试，以及回退事件；由根组件切换到普通布局。
4. 执行格式检查、构建和 diff 检查；由 Master 粘贴构建产物后再验证酒馆真实运行时。

## 验收

- `[special_npc_01_venus]` 仍显示 Venus 专属主题。
- 普通 YAML 加 `特殊立绘` 后显示通用特殊面板，且使用该 URL。
- 无法加载时可重试，或回退到普通面板。
- 无 `特殊立绘` 的现有数据不改变布局。
- `pnpm run build` 成功。
