# 艾璃丝角色预览设计规范

## 目标

为艾璃丝·赛瑞利亚制作独立的角色信息预览页，用于在合并到主角色查看器前确认桌面端与移动端的视觉语言、内容密度和交互结构。

## 角色方向

- 核心意象：水母、梦境、孩子王。
- 机械元素只作为玩具、积木和夸张道具，不采用工业机械风。
- 气质应清新、活泼、柔软，同时保留她作为天穹维护者的可靠感。

## 视觉系统

- 主色：薄荷蓝 `#83DCCB`。
- 梦境色：柔紫 `#A98CE8`。
- 童趣强调：果冻粉 `#F078A6`。
- 主文字：深海军蓝 `#17324A`。
- 背景：低亮度珍珠薄荷色，禁止纯白大面积直射。
- 图形语言：半透明果冻、气泡、软触手曲线、圆形积木节点、轻微星光。
- 不使用外部装饰 SVG；水母与气泡装饰由稳定尺寸的 HTML/CSS 结构组成。

## 布局

- 桌面端采用左侧立绘、右侧资料的双栏结构，两栏共享固定比例容器。
- 移动端使用单栏视图；首页显示立绘与紧凑名牌，详情标签显示资料面板。
- 桌面/移动预览切换只改变布局类，不改变外层宽度计算方式，避免窗口跳动。
- 标签栏是容器内普通文档流元素；移动端允许横向滚动，保存按钮随标签一起滚动。
- 属性采用三上二下；资源值采用三个连接气泡，避免卡片底部融入背景。

## 内容组件

- 名牌：深海军蓝文字、薄荷底、紫粉梦境光点；移动端高度不得超过立绘区域的四分之一。
- 属性：圆角果冻胶囊，数字使用果冻粉，标签使用深海军蓝。
- 资源：三个相连的透明泡泡，分别显示 HP、SP、MP。
- 档案与列表：浅色实底卡片、清晰边框、轻微圆角；不用黑色半透明背景。
- 梦境装饰：低对比星点和涟漪，不得覆盖正文或降低文字对比度。

## 兼容与验收

- 根节点声明 `color-scheme: light`、`isolation: isolate`，并显式设置所有主要文字和背景颜色。
- CSS 选择器限定在预览根节点，避免 SillyTavern 自定义主题影响。
- 不使用 `vh`、不依赖宿主背景、不产生非预期横向滚动。
- 预览至少检查约 1440px 桌面与 412px 手机宽度。
- 所有正文、标签、按钮和数字应达到肉眼清楚可读的对比度。
- 装饰不得裁切人物头部、遮挡文字、错位或在标签切换时改变页面几何尺寸。
