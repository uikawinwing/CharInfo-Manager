# 正式版更新

在「查看器设置 → 更新」查看当前运行版本、最新正式版和上次成功检查时间。「检查更新」会立即查询，不必等待 24 小时；断网、超时或 GitHub 限流后会暂缓再次请求，并显示原因。自动检查以最近一次成功检查为准，每 24 小时运行一次，持续打开酒馆时也会到期检查。

自动更新默认开启。关闭后仍可检查新版，但不会自动选择新候选；已经成功运行的版本会继续保留。开发入口显示「开发版」，不会自动切换到正式版。

## 首次安装

v0.3.7 及更旧版本不含更新器，需要手动升级一次。首次支持自更新的目标版本为 v0.3.8，必须在该正式 Tag 发布且 CDN 文件可访问后安装。版本号只用于说明首次安装目标，不表示它已经发布。

独立安装可以在酒馆助手脚本中使用固定正式版本入口：

```javascript
import 'https://testingcf.jsdelivr.net/gh/uikawinwing/CharInfo-Manager@v0.3.8/dist/char_info_viewer_runtime/index.js';
```

命定之诗角色卡的安装 Loader 在相邻 `Destined-Poem-Card` 仓库的 `tools/lib/resource-loader.mjs` 维护。首次发卡时还需将该仓库 `release.json` 的角色管理库依赖入口更新到已发布的支持版本，然后重新生成并安装脚本。旧 Loader 会优先读取角色变量中的旧版本，不能仅修改 CharInfo 仓库便让所有旧安装获得自更新。

新版 Loader 先导入固定版本作为更新入口，并将 CDN 列表、入口版本和角色变量中的备用版本传给更新器。此入口负责选择实际运行版本；每次发布无需重写玩家脚本，也不使用移动 Tag 或 `@latest`。

## 版本选择与回退

只接受仓库 `uikawinwing/CharInfo-Manager` 中严格符合 `v数字.数字.数字` 的正式 Tag，按数值比较。测试版、预览版和带后缀的 Tag 不自动安装。

正常启动优先选择缓存中更高的正式版，接着使用上次成功运行的版本，再尝试角色变量 `资源版本.角色管理库` 中的备用版本，最后使用安装入口自带的版本。首次安装或升级安装入口时，不会因为缓存仍记录旧正式版而主动降级。每个精确 Tag 通过现有的 jsDelivr CDN 地址加载。

角色变量中的版本仅为备用，不再表示固定运行版本。只有返回了版本匹配的注册信息，并且 Runtime 完成启动，才记录为成功运行；模块导入完成本身不算成功。失败时清理候选实例和样式并继续回退。v0.3.7 及更旧版本没有启动确认协议，只保留为外层 Loader 网络故障时的备用，不参与更新器内部的动态替换。

发现新版后不会中途替换当前聊天。只有确实切换到更高版本并成功启动时才提示一次更新成功。

## 缓存与数据

检查记录使用同一酒馆站点的浏览器持久缓存 `charinfo:stable-updates:v1`，包含最新正式版、成功检查时间、失败退避时间和上次成功运行版本。不同角色卡共用检查记录；请求期间去重。清除浏览器站点数据会清除该缓存。

自动更新开关仍保存在现有脚本设置中。更新不会替换角色资料、聊天变量、档案或其他脚本内容。`sessionStorage['destiny:loaded:角色管理库']` 只在启动确认后记录实际运行版本，用于现有状态栏显示。

## 正式发布

继续通过 `dev → main` PR 发布。发布工作流先执行测试与 lint，选择下一个正式 Patch Tag，将准确的 Tag 写入构建版本模块，再构建并冻结 dist 到发布提交。源码中的版本模块保持开发值；不提交本地构建产物，不手动移动已发布 Tag。

GitHub 平台保护需单独配置：main 要求 PR、`verify` 和 `only-dev`，禁止 force push 和删除；正式 Tag 限制更新与删除。启用 Tag Ruleset 时，不应阻止发布 Action 创建新 Tag。本功能不自动修改平台规则，也不创建 Releases。
